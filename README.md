# 藤花慢慢，山色青青・長野春旅網站

背上小背包，去山裡住幾天。2027.04.24–05.03，成田進、羽田出，高崎、長野與橫濱 10 天 9 夜。

由北海道「雪羽慢旅 hk28」改版而來，北海道與京都網站之前調整過的功能全部沿用：家人同步、離線 PWA、開場動畫、每日交通、MaMa 筆記、小驚喜、收藏與預約、出發前待辦、每日回顧、標點處換行、字放大、手機上放大的按鈕，以及只保留用到的字、瘦身過的手寫標題字型。內容與風格換成長野春天。

## ng1（第一版）

1. **兩版行程可以切換**：首頁標題下方的「行程版本」可以在 **Lomä 山湖版** 和 **藤井莊溪谷版** 之間切換。
   - 4/24–4/26（高崎三天）和 5/1–5/3（橫濱、羽田）兩版共用。
   - 4/27–4/30 依版本顯示不同的行程、標題、插圖、住宿與交通。
   - 兩版的筆記、照片、自訂景點各自分開保存，切回去都還在。
   - 選哪一版只記在這支手機上，全家可以各自比較。環線頁的總覽插畫和 Google 地圖路線也會跟著換。
2. **每日標題與副標**：使用「溫柔故事版」定稿；每天的插圖用小羚羊的 14 張每日場景圖。
3. **配色**照 header 與色票：暖米白 `#F6F2E8` 底、森林綠 `#34594D` 文字與按鈕、藤紫 `#B8A3DC` 點綴，以及嫩葉綠、晴空藍。
4. **小羚羊（カモシカ）**換掉北海道的小雪雀：
   - 換掉的地方包括開場動畫、角落小羚羊、7 個導覽圖示、8 種回顧心情與天氣圖示。
   - 回顧心情是：開心、放鬆、驚喜、滿足、成就感、累了、想睡、雨天小失落。
5. **天氣**：
   - 地點有高崎／藤岡、黑姬／妙高（Lomä 版）、山田溫泉（藤井莊版）、長野／小布施、戶隱、橫濱／羽田。
   - 每個地點都附 tenki.jp 預報連結。
   - 北海道的雪況、降雪提醒用不到，拿掉了。
6. **指南**換成長野春季版內容：出發前待辦 18 項、行李清單、購物清單、旅遊提醒。
7. **交通即時連結**：JR 東日本、道路路況、成田、羽田、氣象廳警報、戶隱開山消息。

## 第一次使用要做的事

1. **Supabase**：沿用北海道網站同一個 Supabase 專案（家人帳號一樣）。資料存在新的 `nagano_sync` 表，所以第一次要到 Supabase → SQL Editor 貼上 `SUPABASE_SETUP.sql` 執行一次，否則登入後會同步失敗。
2. **GitHub Pages**：Settings → Pages → Branch 選 `main`、資料夾 `/ (root)`，網址是 https://clairepan00519-droid.github.io/Nagano2027spring/
3. `config.js` 之後更新網站時不要覆蓋。
