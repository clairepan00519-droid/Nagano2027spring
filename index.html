租車與鐵路原則

展開
  • 6/4 富山取車直接開往白馬；6/12 長野還車，之後只用鐵路。甲地租乙地還要另付異地還車費。
  • 新幹線熱門班次先訂指定席；JR 一般指定席在搭乘日前 1 個月開售。
  • 奧林匹克道路、淺川 Loop Line、國道 292 都是山路，雨霧天減速，以白天移動為主。
  • 6/10 在志賀高原把大行李寄到橫濱，後兩天輕裝。
JR 東日本新幹線及機場列車
D1

富山機場 → 富山站

機場巴士約 20–30 分鐘（估算，依班次）。

D2

富山取車 → 白馬

富山取車，走北陸道接國道 148 到白馬（約 2–2.5 小時，估算），15:00 入住。

D4

白馬 → 戶隱

10:00 退房，奧林匹克道路接淺川 Loop Line（約 1.5 小時，估算）。

D6

戶隱 → 鏡池 → いもり池 → 妙高

清晨鏡池，10:00 退房後去いもり池，15:00 赤倉入住。

D7

妙高 → 中野 → 志賀高原

11:00 退房，一本木公園看玫瑰，中野午餐，國道 292 上山，15:00 入住。

D9

志賀高原 → 湯田中

一沼、琵琶池短走後下山，15:00 入住。

D10

湯田中 → 長野還車 → 橫濱

11:00 退房，長野還車，北陸新幹線到東京轉 JR 到橫濱。

D12

橫濱 → 羽田機場第 3 航廈

京急線，國際線預留起飛前約 3 小時到機場。

行李打包清單

6 月上中旬富山、長野市區白天約 22–27°C，早晚約 12–16°C；白馬、戶隱、志賀高原海拔高，早晚可能只有 10°C 上下，可能遇到梅雨。帶防水外套、刷毛中層與好走的鞋。點擊項目可勾選完成。
