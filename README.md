# 春光•藤花•山色・長野春旅網站

背上小背包，去山裡住幾天。2027.04.24–05.03，成田進、羽田出，高崎、長野與橫濱 10 天 9 夜。

由北海道「雪羽慢旅 hk28」改版而來，北海道與京都網站之前調整過的功能全部沿用：家人同步、離線 PWA、開場動畫、每日交通、MaMa 筆記、小驚喜、收藏與預約、出發前待辦、每日回顧、標點處換行、字放大、手機上放大的按鈕，以及只保留用到的字、瘦身過的手寫標題字型。內容與風格換成長野春天。

## 第一次使用要做的事

1. **Supabase**：沿用北海道網站同一個 Supabase 專案（家人帳號一樣）。資料存在新的 `nagano_sync` 表，所以第一次要到 Supabase → SQL Editor 貼上 `SUPABASE_SETUP.sql` 執行一次，否則登入後會同步失敗。
2. **GitHub Pages**：Settings → Pages → Branch 選 `main`、資料夾 `/ (root)`，網址是 https://clairepan00519-droid.github.io/Nagano2027spring/
3. `config.js` 之後更新網站時不要覆蓋。
